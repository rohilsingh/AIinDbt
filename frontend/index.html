Microsoft Teams (optional, for E2)

Two ways to wire Teams — use either or both:

Outgoing (lets users @mention the bot in a channel): in Teams → channel ⋯ → Connectors → Outgoing Webhooks → set callback URL to POST /api/teams/events, copy the HMAC secret here.
Incoming (lets the app push messages into a channel): channel ⋯ → Connectors → Incoming Webhook, paste the URL above.
